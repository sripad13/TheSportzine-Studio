Keyword research

A research workspace for search demand, intent, SERP competitors and saved editorial opportunities.

Research provider required. Search volume, keyword difficulty and live SERP data need a connected provider such as DataForSEO/YepAPI. We will not invent volumes or difficulty scores. The first integration will support keyword discovery, clustering and a saved newsroom keyword library.

E-E-A-T Editorial Review

Assess evidence of first-hand experience, expertise, authoritativeness and trust. This is an editorial checklist, not a Google ranking score.

Complete the fields to assess editorial trust signals.

Schema Lab

Inspect JSON-LD on a public URL, validate common structural issues, and generate Article / NewsArticle markup from supplied facts.

Generated JSON-LD and validation findings will appear here.

AI Agent Readiness

Check discoverability and access signals relevant to browsing agents: robots policies, llms.txt, Markdown support, AI catalog discovery, and real 404 behaviour. This is not the official Lighthouse Agentic Browsing test.

Enter a public URL to run the checks.

International SEO / Hreflang

Validate language and region tags, self-references, x-default, duplicate locales and canonical alignment from the HTML source of a public URL.

Enter a public URL to validate its language alternates.

Inspired by the open-source Claude SEO project. Selected workflows adapted for Studio. See repository documentation for licence and attribution.

Technical site audit

Run a sitemap-led audit across any public website. Checks technical SEO, structured data, content quality, images, links, publisher trust and AI discovery signals. Browser rendering and Core Web Vitals are intentionally excluded for now.

Up to 30 same-origin sitemap URLs per run.
